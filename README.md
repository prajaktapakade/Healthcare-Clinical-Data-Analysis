# Healthcare-Clinical-Data-Analysis
The Project is related to heart disease data of the patient, the project done in SQL, Power bi and Tableau. The data mostly helps to improve business leads for the Hospitals or doctors
Healthcare Clinical Data Analysis

2. Project Objectives

Analyze patient and age-group distribution.

Calculate heart disease prevalence.

Explore the relationship between hypertension and heart disease.

Identify the most common clinical outcome category.

Calculate average hospital length of stay.

Explore combinations of risk factors associated with heart disease.

3. Tools Used

MySQL – Data analysis and SQL queries

Microsoft Excel – Data cleaning and preliminary analysis

Power BI – Interactive dashboard and visualization

4. Key SQL Questions

What is the total number of patients?

What percentage of patients have heart disease?

How does hypertension relate to heart disease prevalence?

What is the average hospital length of stay?

Which clinical outcome category is most common?

Which risk-factor combination has the highest disease prevalence?
